Configuración · Una sola vez

Cómo activar el backend del taller

Sigue estos pasos desde cualquier dispositivo (móvil o desktop). Tarda menos de 5 minutos y solo se hace una vez.

1

Crear cuenta en JSONBin.io

Ve a jsonbin.io y crea una cuenta gratuita con tu correo. No requiere tarjeta de crédito.

2

Crear el Bin de datos

Una vez dentro, presiona el botón "+ Create Bin".

En el editor que aparece, borra lo que haya y pega exactamente esto:

{"participants":[]}

Presiona "Create Bin" (o el botón de guardar). Verás que aparece un ID en la URL o encima del contenido — ese es tu BIN ID. Cópialo.

3

Obtener tu API Key

En el menú superior de JSONBin, haz clic en tu nombre de usuario o en el ícono de perfil, y entra a "API Keys".

Verás tu Master Key (empieza con $2a$10$...). Cópiala.

4

Subir los archivos a GitHub Pages

Ve a github.com y crea una cuenta gratuita si no tienes.

Crea un repositorio nuevo (botón "New" o "+"). Nómbralo por ejemplo taller-innovacion. Márcalo como Public.

Sube los 3 archivos HTML (index.html, participante.html, admin.html) arrastrándolos al repositorio.

Ve a Settings → Pages, en "Branch" selecciona main y guarda. En 1-2 minutos tu sitio estará en https://TU_USUARIO.github.io/taller-innovacion.

5

Configurar las credenciales en los archivos

Abre la URL de GitHub Pages en tu navegador (móvil o desktop). Entra a participante.html y al admin — en ambos verás un panel gris oscuro en la parte superior.

Pega el BIN ID y la Master Key en los campos correspondientes y presiona "Guardar y verificar conexión" (o "Conectar").

Si aparece "✓ Conectado correctamente", ¡listo! Las credenciales quedan guardadas en el navegador de ese dispositivo.

Repite este paso en cada dispositivo que vaya a usar los archivos (solo una vez por dispositivo).

6

Compartir con los participantes

Comparte la URL directa a participante.html con todos los participantes por WhatsApp, email o QR. Ellos solo necesitan abrir el link — no instalan nada.

Tú abre admin.html en tu pantalla y presiona "Actualizar" para ver las respuestas en tiempo real.

¿Por qué GitHub Pages? Los archivos HTML funcionan perfectamente cuando se sirven desde una URL pública (https://). El problema anterior ocurría porque los archivos abiertos directamente desde el disco (file://...) tienen restricciones de seguridad del navegador que bloquean las llamadas a APIs externas. GitHub Pages resuelve esto de forma gratuita y permanente.
